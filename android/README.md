# Android keyboard

A voice-first keyboard built on [HeliBoard](https://github.com/Helium314/HeliBoard), using the same setup as the desktop:

- Parakeet on the phone for speech, Haiku 5.5 through OpenRouter for cleanup, the same number and paragraph rules.
- A voice panel in place of the keys, with a mic key in the bottom row to get back to it from typing. Swipe typing in the text mode.
- Recording keeps going if you switch apps, collapse the keyboard or rotate the phone; reopen the keyboard and finish the same take.
- Select text and dictate an instruction to edit it, same as on desktop.
- Private (incognito) fields are never saved or synced.

The keyboard source isn't published here yet.
